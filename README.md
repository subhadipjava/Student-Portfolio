# Student Portfolio Website

## Project Overview

This is a responsive student portfolio website developed using HTML5 and CSS3 as part of my Week 1 internship task.

The project demonstrates how a design concept can be converted into a functional static webpage with proper layout, navigation, styling, and responsive design.

## Features

- Responsive navigation bar
- Home/Hero section
- About section
- Skills section
- Projects section
- Contact section
- Footer
- Responsive design for desktop, tablet and mobile
- Hover effects and smooth navigation

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Implementation

### HTML

The `index.html` file is used to create the structure of the webpage. It contains the navigation bar, Home section, About section, Projects section, Contact section and Footer.

### CSS

The `style.css` file is used for colors, typography, spacing, buttons, cards, Flexbox, CSS Grid, hover effects and responsive media queries.
